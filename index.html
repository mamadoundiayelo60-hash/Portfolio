Plateforme Web SIG développée en Python pour l'analyse territoriale, la cartographie interactive et la production automatisée d'indicateurs géographiques.

Python GeoPandas Pandas Shapely Streamlit Folium Leaflet PostGIS

Plateforme interactive d'analyse territoriale

GeoDashboard permet d'importer, visualiser et analyser des données géographiques directement depuis une interface Web interactive.

  • Import et gestion de couches SIG
  • Cartographie interactive
  • Sélection d'un territoire d'analyse
  • Buffer et intersection spatiale
  • Sélection et jointure spatiales
  • Analyse de couverture territoriale
  • Calcul automatique d'indicateurs
  • Export GeoPackage et GeoJSON
  • Sauvegarde de projets
  • Génération automatisée de rapports PDF
